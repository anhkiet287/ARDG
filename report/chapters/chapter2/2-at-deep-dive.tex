\section{Adversarial Attack Algorithms}

The attacks used in this report are best understood as different approximations
to the same inner maximization problem. They vary in perturbation norm, attacker
access, optimization objective, update rule, and role in training or evaluation.
Some attacks, such as PGD-based methods, directly maximize a loss within a fixed
norm ball, while others, such as DeepFool, DDN, and CW, search for low-norm or
boundary-oriented adversarial examples. These differences matter because a model
that is robust to one attack procedure may still fail under another, which is the
core motivation for the attacks-as-domains.

\subsection{Fast Gradient Sign Method with Random Start (FGSM-RS)}

Fast Gradient Sign Method with Random Start (FGSM-RS) is motivated by the need for a cheap first-order evaluation attack. It operates in the whitebox $\ell_\infty$ threat model: the adversary can access the model gradient and must keep the perturbation inside an $\ell_\infty$ ball around the clean input. The base FGSM attack uses a single gradient-sign step to increase the cross-entropy loss \cite{goodfellow2015explaining}.

The objective is the usual untargeted inner maximization of $\ell(f_\theta(x+\delta),y)$ over an $\ell_\infty$ budget. FGSM-RS first samples a random initial perturbation $\delta_0\in\mathcal{S}_\infty(\varepsilon)$ and then takes one sign-gradient step:
\[
x^{\mathrm{adv}}=
\Pi_{(x+\mathcal{S}_\infty(\varepsilon))\cap[0,1]^d}
\left(
x+\delta_0+\alpha\,\mathrm{sign}
\left(\nabla_x \ell(f_\theta(x+\delta_0),y)\right)
\right).
\]
The random start reduces dependence on the clean point's immediate gradient direction and makes the one-step attack less brittle than deterministic FGSM \cite{wong2020fast}.

\subsection{Projected Gradient Descent (PGD)}

Projected Gradient Descent (PGD) is the standard iterative first-order attack used to approximate the adversarial inner maximization \cite{madry2019towards}. It is a whitebox attack because each step uses the current input gradient. In this report, PGD-$\ell_\infty$ is both a source training attack and an evaluation attack, while PGD-$\ell_2$ is used only for evaluation.

For an untargeted $\ell_\infty$ attack, PGD repeatedly ascends the loss and projects the result back to the feasible perturbation set:
\[
x_{t+1}^{\mathrm{adv}}=
\Pi_{(x+\mathcal{S}_\infty(\varepsilon))\cap[0,1]^d}
\left(
x_t^{\mathrm{adv}}+\alpha\,\mathrm{sign}
\left(\nabla_x \ell(f_\theta(x_t^{\mathrm{adv}}),y)\right)
\right).
\]

\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/adv_viz/adv_pgd-ce_3eps.pdf}
\caption[PGD-\(\ell_\infty\) perturbation visualization]{PGD-\(\ell_\infty\) adversarial examples on CIFAR-10 under three perturbation budgets, with normalized perturbation heatmaps.}
\label{fig:ch2_pgd_linf_3eps}
\end{figure}

For an $\ell_2$ variant, the update uses a normalized gradient direction and projection onto the $\ell_2$ ball. The algorithmic intuition is simple: repeated local ascent gives the attack more opportunities to find a high-loss point than a single FGSM step.

PGD is strong, broadly used, and closely tied to adversarial training, but it still depends on the chosen norm, loss, step size, and iteration budget. PGD-AT is the training method that uses PGD-generated examples; PGD-$\ell_\infty$ and PGD-$\ell_2$ are the attacks themselves. This distinction is central to the thesis because Multi-AT, AttackDRO, Cluster-DRO, and AttackDRO++ share PGD-$\ell_\infty$ as a source attack while differing in how generated examples are grouped and weighted.

\subsection{Carlini\textendash Wagner Attack (CW)}

The Carlini\textendash Wagner attack is motivated by the need to test robustness under an optimization objective that differs from standard cross-entropy gradient ascent \cite{carlini2017towards}. It is usually formulated as a whitebox attack and is especially associated with the $\ell_2$ threat model. The adversary searches for a small perturbation that changes the classification decision while controlling perturbation size.

A common CW-style objective combines an $\ell_2$ penalty with a margin-based attack loss:
\[
\min_{\delta}
\|\delta\|_2^2
+ c\,g(x+\delta),
\quad
x+\delta\in[0,1]^d,
\]
where $g(\cdot)$ is chosen so that successful adversarial examples have low objective value. This form makes the attack different from direct cross-entropy maximization: the perturbation norm and the classification margin are optimized together.

CW-$\ell_2$ is a useful held-out evaluation attack because it probes a different loss geometry from PGD and FGSM-style attacks. Its limitation is computational cost, and its strength depends on optimization settings. In this thesis it is used as an evaluation attack only, not as a source attack for training.

\subsection{DeepFool}

DeepFool is motivated by a geometric view of adversarial examples: if the classifier's decision boundary is nearby, a small movement toward that boundary can change the predicted class \cite{moosavi2016deepfool}. It is a whitebox boundary-oriented attack because it uses local gradient information to approximate the classifier near the current point. The report uses DeepFool-$\ell_2$ as a held-out $\ell_2$ evaluation attack.

For a locally linearized binary classifier, the smallest boundary-crossing perturbation has the form
\[
r_t=
-\frac{f(x_t)}{\|\nabla_x f(x_t)\|_2^2}\nabla_x f(x_t).
\]
In multiclass neural networks, DeepFool generalizes this idea by estimating the closest class boundary under a local linear approximation and iteratively updating the input until the predicted class changes or the iteration budget is reached.

\centering
\includegraphics[width=\textwidth]{figures/adv_viz/adv_deepfool-l2_3eps.pdf}

DeepFool is valuable because it emphasizes boundary proximity rather than directly maximizing cross-entropy. Its limitation is that local linearization is only an approximation for nonlinear networks, so it is still an attack heuristic rather than a certificate. In this thesis it complements PGD-$\ell_2$, DDN-$\ell_2$, and CW-$\ell_2$ in the evaluation suite.

\subsection{Decoupled Direction and Norm (DDN)}

Decoupled Direction and Norm (DDN) is motivated by the observation that the direction of an adversarial perturbation and the size of that perturbation can be adapted separately \cite{rony2019decoupling}. It is a whitebox $\ell_2$ attack: the adversary uses gradients to update direction while controlling the perturbation norm. 
At a high level, DDN updates a normalized direction using the loss gradient and then adjusts the current radius depending on attack success:
\[
\delta_{t+1}
=
\rho_{t+1}\,
\frac{\delta_t+\alpha\,\mathrm{Normalize}
\left(\nabla_x \ell(f_\theta(x+\delta_t),y)\right)}
{\left\|\delta_t+\alpha\,\mathrm{Normalize}
\left(\nabla_x \ell(f_\theta(x+\delta_t),y)\right)\right\|_2}.
\]

 
\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/adv_viz/adv_ddn-l2_3eps.pdf}
\caption[DDN perturbation visualization]{DDN-\(\ell_2\) adversarial examples on CIFAR-10 under three perturbation budgets, with normalized perturbation heatmaps.}
\label{fig:ch2_ddn_l2_3eps}
\end{figure}
If the current perturbation is already adversarial, the radius can be reduced; otherwise, it can be increased. This decoupling lets the attack search for small successful $\ell_2$ perturbations without fixing the radius throughout the trajectory. DDN is efficient and well suited to $\ell_2$ adversarial training, but its behavior still depends on update and radius-adjustment choices. 

\subsection{Momentum Iterative Fast Gradient Sign Method (MI-FGSM)}

Momentum Iterative Fast Gradient Sign Method (MI-FGSM) is motivated by the instability that can occur when iterative sign-gradient attacks change direction sharply across steps. It is a whitebox $\ell_\infty$ attack that augments iterative FGSM with a momentum term \cite{dong2018boosting}. The objective remains untargeted loss maximization under an $\ell_\infty$ constraint.

The central update accumulates a normalized gradient direction before applying a sign step:
\[
g_{t+1}
=
\mu g_t+
\frac{\nabla_x \ell(f_\theta(x_t^{\mathrm{adv}}),y)}
{\left\|\nabla_x \ell(f_\theta(x_t^{\mathrm{adv}}),y)\right\|_1},
\quad
x_{t+1}^{\mathrm{adv}}
=
\Pi_{\mathcal{S}_\infty(\varepsilon)}
\left(x_t^{\mathrm{adv}}+\alpha\,\mathrm{sign}(g_{t+1})\right).
\]


\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/adv_viz/adv_mifgsm_3eps.pdf}
\caption[MI-FGSM perturbation visualization]{MI-FGSM-\(\ell_\infty\) adversarial examples on CIFAR-10 under three perturbation budgets, with normalized perturbation heatmaps.}
\label{fig:ch2_mifgsm_3eps}
\end{figure}

The momentum term smooths the update direction and can improve transferability across models.

MI-FGSM is useful because it is close to PGD while still changing the attack dynamics. It can reveal whether robustness depends too narrowly on a particular first-order update rule. In this thesis it is a held-out $\ell_\infty$ evaluation attack and is not used for source adversarial training.

\subsection{TRADES-style Projected Gradient Descent (TPGD)}

The TPGD name is overloaded across software libraries and papers, so its meaning must be fixed for this report. Here, TPGD refers to the TRADES-style PGD attack used by the implemented evaluation code, not to target-label PGD. It is a whitebox $\ell_\infty$ evaluation attack whose objective is based on the divergence between clean and perturbed predictions \cite{zhang2019trades}.


\begin{figure}[H]
\centering
\includegraphics[width=\textwidth]{figures/adv_viz/adv_tpgd_3eps.pdf}
\caption[TPGD perturbation visualization]{TPGD-\(\ell_\infty\) adversarial examples on CIFAR-10 under three perturbation budgets, with normalized perturbation heatmaps.}
\label{fig:ch2_tpgd_3eps}
\end{figure}

The attack maximizes a KL-divergence objective rather than ordinary cross-entropy:
\[
\max_{\delta\in\mathcal{S}_\infty(\varepsilon)}
\operatorname{KL}
\left(
p_\theta(\cdot\mid x)
\;\|\;
p_\theta(\cdot\mid x+\delta)
\right).
\]

Projected gradient ascent then proceeds as in PGD, but with the KL objective replacing the classification loss. The intuition is to find perturbations that make the predictive distribution move away from the clean prediction, even when the ground-truth label is not directly used in the inner objective.

TPGD is useful because it tests a loss objective that differs from cross-entropy PGD. Its limitation is that it is still an $\ell_\infty$ first-order attack and therefore does not replace broader evaluation across norms and attack families. In this thesis it is a held-out evaluation attack included in Mean(8), not a training source attack.

\subsection{AutoAttack}

AutoAttack is motivated by the need for a standardized robustness evaluation that reduces manual attack tuning and combines complementary failure modes \cite{croce2020reliable}. It is used here as a whitebox $\ell_\infty$ stress evaluation. Unlike the individual attacks above, AutoAttack is an evaluation suite rather than a single update rule.

At the wrapper level, AutoAttack evaluates a model using a fixed collection of attacks and reports robustness under the strongest successful component:
\[
\mathrm{Acc}_{\mathrm{AA}}(f_\theta)
=
\frac{1}{n}\sum_{i=1}^{n}
\mathbf{1}
\left[
\forall A\in\mathcal{A}_{\mathrm{AA}},
\; f_\theta(A(x_i,y_i,f_\theta))=y_i
\right].
\]
This expression captures the ensemble logic without deriving the internals of APGD, FAB, or Square Attack.

AutoAttack is stronger and more standardized than a single configured attack, but it is computationally more expensive. This report therefore evaluates AutoAttack-$\ell_\infty$ separately from Mean(8). AutoAttack-512 is used only as a sanity or stress check, while the primary ranking metric remains the eight-attack evaluation suite defined in Chapter~\ref{chap:experimental_setup}.

To keep the attack descriptions focused on the optimization objectives, the grouped qualitative comparison of the full attack suite is provided in Appendix~\ref{app:adv_visualizations}. The individual attack sections include representative three-budget visualizations, while the appendix places the \(\ell_\infty\) and \(\ell_2\) attacks side by side.

The attack suite separates source attacks, held-out evaluation attacks, and the separate AutoAttack stress test; Table~\ref{tab:ch2_attack_summary} records those roles without repeating the exact budgets and step counts deferred to Chapter~\ref{chap:experimental_setup}.



\section{Adversarial Training as Min-Max Optimization}

Adversarial training replaces ERM with a min-max objective in which an inner adversary generates difficult perturbed examples and an outer optimizer updates the model to classify them correctly \cite{madry2019towards}. A standard formulation is
\[
\min_{\theta}
\frac{1}{n}\sum_{i=1}^{n}
\max_{\delta_i\in\mathcal{S}_p(\varepsilon)}
\ell(f_\theta(x_i+\delta_i),y_i).
\]
The inner maximization approximates the worst local perturbation for the current model, while the outer minimization trains the model against those perturbations.

\paragraph{Single-attack adversarial training.}
Single-attack adversarial training chooses one source attack for the inner maximization. PGD-AT uses PGD-generated adversarial examples, while DDN-AT uses DDN-generated adversarial examples. These baselines are important because they isolate the effect of a strong source threat model, but they can also specialize the learned robustness to the attack family, norm, loss, and optimization path used during training.

\paragraph{Multi-attack adversarial training.}
Multi-AT extends the source set by training on a uniform mixture of source attacks. In this report, Multi-AT uses PGD-$\ell_\infty$ and DDN-$\ell_2$ as source attacks, matching the source attacks used by AttackDRO, Cluster-DRO, and AttackDRO++. A compact objective is
\[
\min_{\theta}
\frac{1}{n}\sum_{i=1}^{n}
\frac{1}{|\mathcal{E}|}
\sum_{e\in\mathcal{E}}
\ell(f_\theta(\mathcal{A}_e(x_i,y_i,f_\theta)),y_i),
\]
where $\mathcal{E}$ is the source-attack set. This objective broadens attack coverage relative to a single-source baseline, but uniform averaging does not decide whether weak attack conditions, hard classes, or latent subgroups should receive additional emphasis.

\paragraph{Trade-off intuition.}
Adversarial training has become one of the most widely used empirical defenses, but it introduces practical trade-offs. Training against stronger inner attacks increases computational cost, and improving adversarial accuracy can reduce clean accuracy or shift errors across groups \cite{zhang2019trades,rice2020overfitting,zhao2024adversarialtraining}. Multi-attack training adds another trade-off: expanding the source attack set can improve coverage, but it may also dilute training pressure if all sources are weighted uniformly despite unequal difficulty.

The later methodology builds on this background by asking how source attacks and discovered groups should be weighted during training. Chapter~\ref{chap:related_work} reviews prior work that motivates this question, and Chapter~\ref{chap:methodology} defines the specific group-aware methods evaluated in this report.
